# Review courses before setup

Use this at the beginning of a semester, before asking Codex to make changes
to Canvas.

## Prompt

```text
I want to start setting up my {{semester}} courses.

For this first session, work read-only. Do not make any changes to Canvas.

Identify the courses I will be teaching, inspect their existing course-level
configuration and content, and summarize their current state. Do not inspect
rosters, enrollments, submissions, grades, or other student-level data.

Then propose a plan for setting up each course and tell me what questions you
need answered before making changes.

Stop after presenting the plan. Do not execute the proposed changes yet.
```
